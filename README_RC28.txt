2. 예금이자 계산기

3. 복리 계산기
   - 초기금액 / 월 추가납입 / 연 수익률 / 기간
   - 총 납입원금 / 복리 증가분 / 연도별 성장 막대

[생활·날짜]
4. 날짜 차이 계산기

   - 토·일 제외 / 추가 휴무일 직접 입력 / 시작·종료 포함 선택
6. 근속기간 계산기
   - 년·개월·일 / 총 일수 / 총 개월 / 다음 입사기념일

[쇼핑·가격]
7. 할인 전 가격 계산기

8. 단가 비교 계산기
   - 100g / 100ml / 개당 / m당 A·B 가격 비교
9. 중복 할인 계산기
   - 1차/2차 할인 + 쿠폰 + 포인트
