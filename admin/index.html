실제 등록 순서

프로그램 또는 LISP의 ZIP 파일과 대표 이미지·스크린샷을 준비합니다.
이 화면에서 정보를 입력하고 product.json을 저장합니다.
사이트의 products/programs/ 또는 products/lisp/ 아래에 고유 ID 폴더를 만듭니다.
product.json, 이미지, 다운로드 ZIP을 같은 제품 폴더에 넣습니다.
catalog.json에 생성된 항목을 추가하면 메인과 상세 페이지에서 자동 노출됩니다.
