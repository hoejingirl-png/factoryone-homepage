PDF 페이지 편집

PDF 페이지의 순서를 바꾸고, 필요 없는 페이지를 삭제하거나 회전해 새 PDF로 저장합니다. 문서 구조를 정리하는 작업에 적합합니다.

페이지 순서삭제·회전새 PDF 저장

PDF 선택

편집할 PDF 파일을 선택하세요.
PDF를 선택한 뒤 페이지를 불러오세요.

가능한 편집

페이지 삭제가능
90° 회전가능
순서 변경가능

사용방법

  1. 편집할 PDF를 선택합니다.
  2. 페이지 미리보기에서 순서와 방향을 확인합니다.
  3. 삭제·회전·재배치를 적용합니다.
  4. 새 PDF로 생성해 저장합니다.

처리 기준과 주의사항

페이지 단위 편집 도구입니다. PDF 안의 문장이나 글꼴을 직접 수정하는 본문 편집 기능과는 다릅니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

스캔 PDF에서 거꾸로 들어간 2페이지를 회전하고, 빈 5페이지를 삭제한 뒤 정상 순서로 다시 저장할 수 있습니다.

자주 묻는 질문

PDF 문장도 고칠 수 있나요?

현재는 페이지 단위 편집 중심이며 본문 텍스트 편집 기능은 아닙니다.

원본 파일에 바로 덮어쓰나요?

새 결과 파일을 만드는 방식으로 사용하는 것이 안전합니다.
