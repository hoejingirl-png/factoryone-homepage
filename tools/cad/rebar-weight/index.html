철근 중량 계산기 - D10~D32 길이·수량·톤 환산

철근 직경과 1본 길이, 수량을 입력해 단위중량·1본 중량·총중량·톤수·여유율·예상 재료비를 한 번에 계산합니다.

D10~D32kg·ton 환산로스율·재료비
REBAR WEIGHT REPORT

철근 조건 입력

STEEL QUANTITY REPORT-
단위중량-d² ÷ 162 근사식
1본 중량-단위중량 × 길이
순 총중량-로스 전
여유 포함 총중량-kg
톤 환산-1t = 1,000kg
총 연장-길이 × 수량
예상 재료비-입력한 톤당 단가 기준
여유 중량-로스분만 별도
d²/162는 현장에서 널리 쓰는 철근 단위중량 근사식입니다. 실제 발주·검수에는 적용 규격, 제조사 성적서, 프로젝트 기준을 우선하세요.

사용방법

  1. 철근 직경(D10~D32)을 선택합니다.
  2. 1본 길이와 필요한 수량을 입력합니다.
  3. 절단·가공 손실을 고려한 여유율을 입력합니다.
  4. kg, ton, 총 연장과 선택 입력한 단가 기준 재료비를 확인합니다.

계산 기준

단위중량(kg/m) ≈ d² ÷ 162
1본 중량 = 단위중량 × 길이
총중량 = 1본 중량 × 수량 × (1 + 여유율)

공식은 직경을 mm로 넣는 현장 근사식입니다. 규격표와 약간의 차이가 날 수 있습니다.

실제 사용 예시

D13, 길이 8m, 100본이면 근사 단위중량은 약 1.043kg/m이고 순중량은 약 834kg입니다. 여유율 5%를 넣으면 발주 참고 중량은 약 876kg 수준으로 표시됩니다.

자주 묻는 질문

공식값과 철강사 표가 조금 다른 이유는?

d²/162가 근사식이기 때문입니다. 최종 발주는 해당 규격의 표준 단위중량을 확인하세요.

겹침이음 길이도 자동 포함되나요?

아니요. 이음·정착·가공에 필요한 추가 길이는 길이 또는 여유율에 직접 반영해야 합니다.
