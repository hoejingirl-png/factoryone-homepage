도면 축척 계산기 - 1:100 실제길이·출력비율 변환

도면 길이와 1:N 축척을 입력해 실제 길이를 구하고, 실제 길이를 도면 길이로 역산하며 서로 다른 축척 사이 출력 확대·축소 비율도 계산합니다.

도면→실제실제→도면출력비율 계산
DRAWING SCALE

축척 조건 입력

SCALE REPORT도면 ↔ 실제
도면 길이 → 실제-mm도 함께 표시
실제 길이 → 도면-현재 축척 기준
축척 변경 출력비율-100→50이면 200%
축척 배율-변경 후 도면 크기 비

사용방법

  1. 도면에서 잰 길이와 축척 1:N을 입력합니다.
  2. 실제 길이를 m와 mm로 확인합니다.
  3. 실제 치수를 도면상 길이로 역산할 수도 있습니다.
  4. 축척을 바꿔 출력할 때 필요한 확대·축소 퍼센트도 확인합니다.

계산 기준

실제길이(mm) = 도면길이(mm) × 축척분모 N
도면길이(mm) = 실제길이(mm) ÷ N
출력비율(%) = 기존 축척분모 ÷ 새 축척분모 × 100

실제 사용 예시

1:100 도면에서 50mm라면 실제는 5,000mm, 즉 5m입니다. 1:100 도면을 1:50 크기로 바꾸려면 도면 선형 크기는 2배이므로 200%가 됩니다.

자주 묻는 질문

출력비율만 바꾸면 CAD 축척도 자동으로 바뀌나요?

출력 환경과 뷰포트 설정에 따라 다릅니다. 이 값은 선형 길이 비율 계산용입니다.

단위가 cm인 도면도 되나요?

현재 도면 입력은 mm 기준입니다. 다른 단위는 mm로 바꿔 입력하세요.
