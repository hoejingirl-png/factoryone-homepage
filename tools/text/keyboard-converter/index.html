이 도구가 필요한 경우

메신저나 검색창에서 한/영 전환을 깜빡하고 “dkssudgktpdy”처럼 입력했을 때 다시 타이핑하지 않고 복구하는 데 유용합니다.

핵심 포인트

  • 두벌식 자판 기준 영문 키 입력을 한글 음절로 조합합니다.
  • 한글 음절을 두벌식 영문 키 입력으로 풀어냅니다.
  • 공백·숫자·일반 기호는 가능한 그대로 유지합니다.

사용 방법

1. 문자열 붙여넣기

잘못 입력한 문장을 그대로 넣습니다.

2. 방향 선택

영문→한글 또는 한글→영문을 고릅니다.

3. 결과 확인

자판 위치 기준으로 변환된 문자열을 봅니다.

4. 복사

결과를 복사해 원래 입력할 곳에 붙여넣습니다.

계산·처리 기준

대한민국에서 널리 쓰이는 두벌식 자판 배열을 기준으로 키 위치를 변환합니다. 영문→한글은 초성·중성·종성 조합이 가능한 경우 한글 음절로 합성합니다. 특수 조합이나 세벌식 자판은 지원하지 않습니다.

실제 예시

영문 상태에서 “dkssudgktpdy”라고 입력했다면 두벌식 키 위치를 한글로 바꿔 “안녕하세요”로 조합합니다.

자주 묻는 질문

세벌식도 지원하나요?

현재는 두벌식 자판 기준입니다.

대문자도 처리되나요?

Shift가 필요한 쌍자음·일부 모음에 해당하는 영문 대문자를 일부 반영합니다.

비밀번호를 넣어도 되나요?

민감한 비밀번호는 어떤 웹도구에도 입력하지 않는 편이 안전합니다.

문장이 완벽하게 복구되지 않을 수 있나요?

자판 위치 변환 도구이므로 원래 의도한 문맥까지 추론하지는 않습니다.
