사용방법

  1. 줄 단위 데이터를 붙여넣습니다.

처리 기준

문자 정렬은 한국어 localeCompare의 숫자 인식 옵션을 사용하고 숫자 모드는 각 줄의 숫자값을 기준으로 정렬합니다.

실제 사용 예시

파일명 목록이나 순번이 섞인 작업목록을 가나다 또는 숫자순으로 다시 배치할 수 있습니다.
