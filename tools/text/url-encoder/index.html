이 도구가 필요한 경우

한글·공백·특수문자를 URL용 문자열로 인코딩하거나 원래 텍스트로 복원합니다. 개발·문서 작업 중 잠깐 필요한 변환을 설치 없이 빠르게 처리할 수 있습니다.

핵심 포인트

  • 입력과 결과를 한 화면에서 비교합니다.
  • 결과를 바로 복사해 다음 작업에 사용할 수 있습니다.
  • 모바일과 PC 브라우저에서 사용할 수 있습니다.

사용 방법

1. 값 입력

변환하거나 생성할 조건을 입력합니다.

2. 옵션 확인

필요한 처리 방식과 조건을 선택합니다.

3. 실행

버튼을 눌러 결과를 생성합니다.

4. 결과 복사

확인한 결과를 복사해 사용합니다.

계산·처리 기준

encodeURIComponent와 decodeURIComponent를 사용해 UTF-8 기반 퍼센트 인코딩을 처리합니다. 전체 URL 구조가 아니라 입력 문자열 단위를 변환합니다.

실제 예시

한글과 공백이 포함된 검색어를 인코딩하면 주소의 쿼리 값에 넣기 쉬운 % 형태 문자열로 바뀝니다.

자주 묻는 질문

전체 URL을 그대로 인코딩해도 되나요?

가능하지만 : / ? 같은 URL 구조 문자도 변환됩니다. 보통은 쿼리 값처럼 필요한 부분만 인코딩합니다.

플러스 기호와 공백은 같은가요?

이 도구는 encodeURIComponent 기준이라 공백을 %20으로 처리합니다.

잘못된 % 문자열은 어떻게 되나요?

디코딩할 수 없는 형식이면 오류 안내를 표시합니다.

한글도 지원하나요?

네. 브라우저의 UTF-8 처리 기준으로 한글을 변환합니다.
