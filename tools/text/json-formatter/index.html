이 도구가 필요한 경우
JSON 문자열을 보기 좋게 들여쓰기하고 문법 오류 위치를 확인합니다. 개발·문서 작업 중 잠깐 필요한 변환을 설치 없이 빠르게 처리할 수 있습니다.
핵심 포인트
  • 입력과 결과를 한 화면에서 비교합니다.
  • 결과를 바로 복사해 다음 작업에 사용할 수 있습니다.
  • 모바일과 PC 브라우저에서 사용할 수 있습니다.
사용 방법
1. 값 입력
변환하거나 생성할 조건을 입력합니다.
2. 옵션 확인
필요한 처리 방식과 조건을 선택합니다.
3. 실행
버튼을 눌러 결과를 생성합니다.
4. 결과 복사
확인한 결과를 복사해 사용합니다.
계산·처리 기준
브라우저의 JSON.parse로 문법을 검증하고 JSON.stringify를 이용해 2칸 들여쓰기 또는 한 줄 형식으로 다시 만듭니다.
실제 예시
공백 없이 붙어 있는 JSON을 입력해도 정리 버튼을 누르면 키와 값의 구조가 줄바꿈과 들여쓰기로 표시됩니다.
자주 묻는 질문
입력한 JSON이 서버로 전송되나요?
이 도구의 변환은 현재 페이지의 브라우저 JavaScript에서 처리합니다.
주석이 들어간 JSON도 되나요?
표준 JSON에는 주석이 허용되지 않아 오류로 표시됩니다.
마지막 쉼표도 허용되나요?
표준 JSON 문법에서는 마지막 항목 뒤의 불필요한 쉼표를 허용하지 않습니다.
압축은 파일 압축인가요?
아닙니다. 공백과 줄바꿈을 제거해 JSON 문자열을 한 줄로 만드는 기능입니다.
