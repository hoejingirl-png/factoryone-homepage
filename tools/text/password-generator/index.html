랜덤 비밀번호 생성기

길이와 문자 종류를 선택해 브라우저에서 강한 랜덤 비밀번호를 생성합니다.

비밀번호 생성기 바로 사용

생성 결과 -

이 도구가 필요한 경우

길이와 문자 종류를 선택해 브라우저에서 강한 랜덤 비밀번호를 생성합니다. 개발·문서 작업 중 잠깐 필요한 변환을 설치 없이 빠르게 처리할 수 있습니다.

핵심 포인트

  • 입력과 결과를 한 화면에서 비교합니다.
  • 결과를 바로 복사해 다음 작업에 사용할 수 있습니다.
  • 모바일과 PC 브라우저에서 사용할 수 있습니다.

사용 방법

1. 값 입력

변환하거나 생성할 조건을 입력합니다.

2. 옵션 확인

필요한 처리 방식과 조건을 선택합니다.

3. 실행

버튼을 눌러 결과를 생성합니다.

4. 결과 복사

확인한 결과를 복사해 사용합니다.

계산·처리 기준

브라우저 Web Crypto의 crypto.getRandomValues를 사용합니다. 선택한 각 문자 종류가 최소 한 번 포함되도록 만든 뒤 순서를 다시 섞습니다.

실제 예시

길이 16에 대문자·소문자·숫자·특수문자를 모두 선택하면 네 종류를 모두 포함한 16자 랜덤 문자열을 생성합니다.

자주 묻는 질문

사이트에 비밀번호가 저장되나요?

이 도구의 생성 로직은 현재 페이지의 브라우저에서 실행되며 별도의 저장 기능은 없습니다.

몇 글자가 좋은가요?

서비스 정책에 맞춰 충분히 긴 비밀번호를 사용하는 것이 좋습니다. 이 도구는 8~64자를 지원합니다.

모든 사이트에서 특수문자를 쓸 수 있나요?

사이트마다 허용 문자 정책이 다르므로 가입하려는 서비스의 규칙을 확인해야 합니다.

같은 비밀번호를 여러 사이트에서 써도 되나요?

권장하지 않습니다. 서비스마다 서로 다른 비밀번호를 사용하는 편이 안전합니다.
