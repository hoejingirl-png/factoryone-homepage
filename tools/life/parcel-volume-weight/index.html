박스 가로·세로·높이로 부피를 계산하고, 국제배송에서 쓰는 부피무게를 나눗수까지 직접 지정해 비교합니다.

이 도구가 필요한 경우

해외배송·항공택배처럼 박스가 가볍지만 큰 경우 실제 중량보다 부피무게 기준이 더 커질 수 있어 포장 크기를 미리 비교할 때 유용합니다.

핵심 포인트

  • cm 입력으로 L와 m³ 부피를 계산합니다.
  • 가로×세로×높이÷나눗수 방식으로 부피무게를 계산합니다.
  • 운송사마다 다른 나눗수를 직접 입력할 수 있습니다.

사용 방법

1. 박스 치수 입력

가로·세로·높이를 cm로 입력합니다.

2. 실중량 입력

포장 완료 후 실제 무게를 입력합니다.

3. 나눗수 확인

이용할 운송사의 부피무게 기준을 확인해 넣습니다.

4. 비교

실중량과 부피무게 중 큰 값을 확인합니다.

계산·처리 기준

박스 부피는 가로×세로×높이입니다. 부피무게는 흔히 cm 기준 가로×세로×높이÷특정 나눗수로 계산하지만, 그 나눗수와 청구 규칙은 택배사·항공사·서비스에 따라 다릅니다. 기본값 5000은 예시이며 실제 발송 전 해당 운송사의 최신 규정을 반드시 확인하세요.

실제 예시

40×30×25cm 박스는 30L입니다. 나눗수 5000이면 부피무게는 6kg입니다. 실제 중량이 3kg이라면 부피 기준이 더 크게 나옵니다.

자주 묻는 질문

5000이 모든 택배사 공통인가요?

아닙니다. 서비스마다 5000, 6000 등 다른 기준을 쓸 수 있어 직접 확인해야 합니다.

국내 택배 요금도 바로 계산되나요?

아니요. 이 도구는 부피와 부피무게 비교용이며 실제 택배 요금표는 반영하지 않습니다.

박스 여러 개도 계산되나요?

동일 크기·무게 박스라면 수량을 입력해 총 부피와 총 실중량을 볼 수 있습니다.

단위가 inch라면 어떻게 하나요?

현재 입력은 cm 기준입니다. inch는 먼저 단위 변환기를 이용하세요.
