영업일 계산기 - 주말·직접 지정 휴무일 제외

기간을 입력하고 토·일과 직접 지정한 공휴일·회사휴무일을 제외해 실제 영업일 또는 근무가능 일수를 계산합니다.

추가 휴무일-평일과 겹친 입력값
대한민국 공휴일을 자동으로 불러오는 기능이 아니라, 사용자가 실제 휴무일을 직접 입력하는 방식입니다. 회사·기관별 휴무일이 다를 때 오히려 정확하게 맞출 수 있습니다.

사용방법

  1. 계산할 시작일과 종료일을 입력합니다.
  2. 회사휴무·공휴일 등을 YYYY-MM-DD 형식으로 쉼표 구분해 입력합니다.
  3. 시작일과 종료일 포함 여부를 선택합니다.
  4. 전체 달력일과 실제 영업일을 비교합니다.

계산 기준

영업일 = 기간 내 월~금 − 직접 입력한 평일 휴무일

토·일은 자동 제외하고 국가 공휴일은 자동 조회하지 않습니다.

실제 사용 예시

납기 계산에서 30일 달력기간이 실제 며칠의 근무일인지 확인하고, 회사 창립기념일 같은 추가 휴무일까지 직접 빼서 볼 수 있습니다.

자주 묻는 질문

한국 공휴일이 자동으로 들어가나요?

아니요. 연도별 변동과 기관별 휴무 차이를 피하기 위해 직접 입력 방식입니다.

토요일 근무 회사는?

현재 토·일을 주말로 고정합니다. 토요일 근무형 옵션은 추후 확장 가능합니다.
