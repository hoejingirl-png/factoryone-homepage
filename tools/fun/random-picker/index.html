랜덤 추첨기

이름·번호·메뉴 후보를 줄바꿈으로 넣고 중복 없이 원하는 인원만큼 무작위 추첨하며 결과 순서까지 확인합니다.

이름 추첨중복 없는 당첨랜덤 순서

후보 목록에서 무작위 추첨

당첨 결과-
유효 후보-
추첨 인원-

이 도구가 필요한 경우

이벤트 당첨자, 점심 메뉴, 발표 순서처럼 후보가 여러 개일 때 직접 고르는 편향을 줄이고 무작위로 결과를 정하고 싶을 때 사용할 수 있습니다.

핵심 포인트

  • 브라우저의 crypto.getRandomValues를 이용해 순서를 섞습니다.
  • 당첨 인원 수만큼 중복 없이 앞에서 선택합니다.
  • 같은 이름을 하나로 합칠지 입력 줄 그대로 둘지 선택할 수 있습니다.

사용 방법

1. 후보 입력

한 줄에 하나씩 이름이나 항목을 넣습니다.

2. 인원 선택

몇 명 또는 몇 개를 뽑을지 정합니다.

3. 추첨

무작위로 섞은 뒤 결과를 확인합니다.

4. 복사

당첨자나 전체 랜덤 순서를 복사합니다.

계산·처리 기준

Fisher–Yates 방식으로 배열을 섞으며 난수는 가능한 경우 브라우저의 Web Crypto API를 이용합니다. 일상적인 추첨 편의를 위한 도구이며 법적·금전적 이해관계가 큰 공인 추첨 시스템을 대신하지 않습니다.

실제 예시

후보 20명을 넣고 당첨 인원을 3명으로 설정하면 전체 후보를 무작위로 섞은 뒤 앞의 3명을 당첨 결과로 표시합니다.

자주 묻는 질문

같은 사람이 두 번 뽑히나요?

한 번의 추첨 안에서는 같은 후보 항목을 중복 선택하지 않습니다.

같은 이름을 두 줄 넣으면 어떻게 되나요?

“같은 이름 1개로 보기”를 선택하면 하나로 합치고, “입력한 줄 그대로”를 선택하면 별도 후보로 취급합니다.

결과를 다시 재현할 수 있나요?

현재는 시드 고정 기능이 없어 같은 입력이라도 다시 추첨하면 결과가 달라질 수 있습니다.

공식 경품 추첨에 써도 되나요?

간단한 이벤트에는 편리하지만 법적 증빙이나 감사가 필요한 추첨은 별도 검증 가능한 시스템을 사용하세요.
