PDF 문서정보 수정

PDF의 제목·작성자·주제 등 문서 메타데이터를 확인하고 수정합니다. 파일명과 별개로 문서 속성을 정리할 때 사용합니다.

문서 정보 수정

PDF를 선택하세요.
PDF 문서 속성의 제목·작성자·주제·키워드를 수정합니다.

메타정보

파일명과 별개로 PDF 내부에 저장되는 문서 정보입니다.

사용방법

  1. PDF 파일을 선택합니다.
  2. 현재 문서정보를 확인합니다.
  3. 필요한 제목·작성자 등 항목을 수정합니다.
  4. 수정된 문서정보를 포함한 PDF를 저장합니다.

처리 기준과 주의사항

PDF 메타데이터 필드를 수정하는 기능이며 본문 내용이나 파일명 자체를 바꾸는 기능은 아닙니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

다운로드한 PDF 제목이 비어 있거나 이상하게 표시될 때 제목과 작성자를 정리해 문서관리 프로그램에서 찾기 쉽게 만들 수 있습니다.
