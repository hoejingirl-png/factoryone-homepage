이미지의 가로·세로 픽셀을 조절해 원하는 해상도로 다시 저장합니다. 웹 업로드·썸네일·문서 삽입용 크기를 만들 때 유용합니다.

이미지 선택

사용방법

  1. 크기를 바꿀 이미지를 선택합니다.
  2. 원본 가로·세로 픽셀을 확인합니다.
  3. 원하는 출력 크기를 입력합니다.
  4. 결과를 확인하고 새 이미지로 저장합니다.

처리 기준과 주의사항

브라우저 캔버스에서 지정된 픽셀 크기로 다시 그립니다. 원본보다 크게 확대하면 세부 선명도가 새로 생기는 것은 아닙니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

4032×3024 사진을 웹 업로드용 1200px 폭으로 줄여 전송 속도와 문서 편집 편의성을 높일 수 있습니다.
