이 도구가 필요한 경우

채용·학교·관공서·커뮤니티 등에 사진을 올릴 때 “100KB 이하”처럼 용량 제한이 걸리는 경우에 유용합니다. 단순 압축률 대신 최종 파일 크기를 목표로 잡습니다.

핵심 포인트

  • 목표 KB 이하가 될 때까지 품질을 자동 탐색합니다.
  • 큰 사진은 최대 가로폭을 적용해 불필요한 픽셀도 줄입니다.
  • 업로드 없이 브라우저 안에서 처리합니다.

사용 방법

1. 사진 선택

JPG·PNG·WEBP 파일을 불러옵니다.

2. 목표 입력

100KB, 200KB처럼 원하는 상한을 입력합니다.

3. 자동 조정

화질과 크기를 반복 계산해 목표 이하를 찾습니다.

4. 비교·저장

원본과 결과 용량을 확인한 뒤 내려받습니다.

계산·처리 기준

브라우저 Canvas로 이미지를 다시 그린 뒤 JPEG 품질을 이진 탐색합니다. 품질만으로 목표 용량에 도달하지 못하면 설정한 최대 가로폭을 기준으로 축소합니다. 투명 PNG는 JPEG로 바뀌면서 투명 영역이 흰색으로 처리될 수 있습니다.

실제 예시

3.8MB 사진을 목표 100KB, 최대 가로폭 1600px로 설정하면 도구가 여러 품질 값을 시험해 100KB 이하에 가장 가까운 결과를 찾습니다. 사진 내용에 따라 실제 최종 용량은 달라집니다.

자주 묻는 질문

정확히 100KB가 되나요?

파일 내용과 JPEG 인코딩 특성 때문에 정확히 100KB가 아니라 100KB 이하에 최대한 가깝게 맞춥니다.

원본이 서버로 올라가나요?

아니요. 이 도구의 이미지 처리는 현재 브라우저 안에서 수행됩니다.

PNG도 가능한가요?

불러올 수 있지만 목표 용량 압축 결과는 JPEG로 저장합니다.

화질이 너무 떨어지면 어떻게 하나요?

목표 KB를 높이거나 최대 가로폭 값을 키우면 화질을 더 보존할 수 있습니다.
