이 도구가 필요한 경우

블로그·중고거래·커뮤니티에 사진을 올리기 전 차량번호, 문서 속 전화번호, 사람 얼굴처럼 공개하고 싶지 않은 부분을 빠르게 가릴 때 사용할 수 있습니다.

핵심 포인트

  • 마우스나 터치로 직접 영역을 지정합니다.
  • 모자이크와 완전 검정 가리기를 선택할 수 있습니다.
  • 원본을 덮어쓰지 않고 새 PNG로 저장합니다.

사용 방법

1. 사진 불러오기

가릴 정보가 있는 사진을 선택합니다.

2. 영역 드래그

캔버스에서 사각형으로 영역을 지정합니다.

3. 방식 적용

모자이크 또는 검정 가리기를 적용합니다.

4. 확인·저장

민감정보가 충분히 가려졌는지 확인 후 저장합니다.

계산·처리 기준

선택 영역의 픽셀을 작은 해상도로 축소한 뒤 다시 확대해 모자이크를 만듭니다. 검정 가리기는 해당 픽셀을 불투명 검정으로 덮습니다. 민감정보 보호 목적이라면 저장 결과를 확대해서 원문이나 번호가 식별되지 않는지 직접 확인하세요.

실제 예시

차량 사진에서 번호판 영역을 드래그하고 “모자이크”를 적용한 뒤, 번호가 여전히 읽힌다면 강도를 높여 한 번 더 적용합니다. 주민번호나 계좌번호처럼 민감도가 높은 정보는 검정 가리기가 더 확실합니다.

자주 묻는 질문

자동으로 얼굴을 찾아주나요?

현재 버전은 자동 얼굴인식이 아니라 사용자가 직접 영역을 지정하는 방식입니다.

모자이크를 원래대로 복원할 수 있나요?

도구에서 직전 작업은 실행 취소할 수 있지만, 저장된 모자이크 이미지에서 원본 정보를 복원하는 기능은 제공하지 않습니다.

휴대폰에서도 되나요?

터치 드래그를 지원하도록 구성했습니다. 화면이 작은 경우 확대보다 원본 확인을 우선하세요.

가리기만 하면 개인정보가 완전히 안전한가요?

검정 가리기는 해당 픽셀을 덮지만 사진 파일의 다른 메타데이터까지 제거하는 기능은 별도 EXIF 제거 도구를 이용하는 것이 좋습니다.
