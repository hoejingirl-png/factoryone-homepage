자주 묻는 질문

파일이 서버에 업로드되나요?

현재 브라우저에서 처리하도록 구현된 도구는 사용자의 브라우저 안에서 작업합니다. 외부 라이브러리를 불러오는 경우 인터넷 연결은 필요할 수 있습니다.

모바일에서도 사용할 수 있나요?

대부분의 도구는 모바일 브라우저에서도 사용할 수 있도록 반응형으로 구성하지만, 큰 PDF나 고해상도 이미지는 PC가 더 안정적일 수 있습니다.
