DPI·픽셀·인쇄크기 계산기

cm·mm·inch와 DPI를 입력해 필요한 픽셀을 계산하거나, 현재 픽셀 이미지가 몇 cm로 인쇄되는지 역산합니다.

이 도구가 필요한 경우

인쇄물·증명사진·포스터를 만들 때 “몇 픽셀이 필요한지” 또는 가진 이미지가 특정 DPI에서 실제 몇 cm로 인쇄되는지 확인할 때 사용합니다.

핵심 포인트

  • cm와 DPI에서 필요한 픽셀을 계산합니다.
  • 픽셀과 DPI에서 인쇄 가능한 cm를 역산합니다.
  • 150·200·300DPI 등 작업 기준을 직접 입력할 수 있습니다.

사용 방법

1. 크기 입력

원하는 인쇄 가로·세로 cm를 입력합니다.

2. DPI 입력

제출처나 인쇄소 요구 값을 넣습니다.

3. 픽셀 계산

필요한 가로·세로 픽셀을 확인합니다.

4. 역산

현재 이미지 픽셀로 가능한 인쇄 크기도 확인합니다.

계산·처리 기준

픽셀 = (cm ÷ 2.54) × DPI입니다. 반대로 인쇄 cm = (픽셀 ÷ DPI) × 2.54입니다. DPI는 해상도 표기 기준일 뿐, 작은 이미지를 수치만 높인다고 실제 디테일이 새로 생기지는 않습니다.

실제 예시

10×15cm를 300DPI로 출력하려면 약 1181×1772px가 필요합니다. 1200px 가로 이미지는 300DPI 기준 약 10.16cm 폭으로 인쇄됩니다.

자주 묻는 질문

DPI와 PPI는 같은 건가요?

엄밀히는 용도가 다르지만 이미지 인쇄 크기 계산에서는 픽셀 밀도 기준으로 같은 수치처럼 사용되는 경우가 많습니다.

300DPI면 무조건 선명한가요?

원본 이미지 자체의 픽셀과 품질이 충분해야 합니다.

웹 이미지에도 DPI가 중요한가요?

웹 화면에서는 실제 픽셀 크기가 더 직접적입니다. DPI는 주로 인쇄 크기를 정할 때 의미가 큽니다.

소수점 픽셀은 어떻게 하나요?

실제 이미지는 정수 픽셀을 사용하므로 계산 결과를 반올림합니다.
