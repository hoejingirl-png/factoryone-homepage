PDF 페이지 추출

긴 PDF에서 필요한 페이지만 골라 새 PDF로 저장합니다. 페이지 범위를 확인하고 원하는 부분만 빠르게 분리할 수 있습니다.

페이지 선택새 PDF 생성브라우저 처리

PDF와 페이지 범위

PDF 파일을 선택하세요.
페이지 번호는 1부터 시작합니다.

PDF 도구

PDF 합치기이미지 → PDFPDF → 이미지

사용방법

  1. PDF 파일을 선택합니다.
  2. 추출하려는 페이지 번호 또는 범위를 입력합니다.
  3. 추출을 실행해 새 PDF를 만듭니다.
  4. 결과 파일의 페이지 수를 확인하고 저장합니다.

처리 기준과 주의사항

원본 PDF에서 지정한 페이지 객체만 새 PDF로 복사합니다. 원본 페이지 번호를 잘못 입력하면 원하는 결과가 나오지 않을 수 있습니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

30페이지 보고서에서 3~7페이지만 제출해야 한다면 해당 범위를 지정해 5페이지짜리 PDF를 따로 만들 수 있습니다.

자주 묻는 질문

원본 PDF는 바뀌나요?

아니요. 새 PDF를 생성하는 방식이므로 원본 파일은 그대로 유지됩니다.

여러 구간도 가능한가요?

현재 입력 방식이 지원하는 페이지 지정 규칙에 따라 여러 페이지를 선택할 수 있습니다.
