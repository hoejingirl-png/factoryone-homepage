온도 변환기 - 섭씨·화씨·켈빈

섭씨 °C, 화씨 °F, 켈빈 K 사이 온도를 양방향으로 변환합니다.

즉시 변환양방향결과 복사
CONVERSION REPORT

변환값 입력

RESULT-
변환 결과-입력 즉시 계산

사용방법

  1. 값과 변환 전·후 단위를 선택합니다.
  2. 결과가 즉시 갱신됩니다.
  3. 단위 바꾸기로 방향을 뒤집을 수 있습니다.
  4. 결과를 복사해 다른 문서에서 사용합니다.

변환 기준

각 단위를 공통 기준단위로 환산한 뒤 목표 단위로 다시 나누는 방식입니다. 온도는 섭씨를 중간 기준으로 사용합니다.

실제 사용 예시

해외 규격, 현장 치수, 파일 용량처럼 서로 다른 단위로 표시된 값을 같은 기준으로 빠르게 맞출 때 사용할 수 있습니다.
