이미지 회전·뒤집기

사진을 90도 단위로 회전하거나 좌우·상하로 뒤집어 방향을 바로잡습니다. 휴대폰 사진이나 스캔 이미지 정리에 유용합니다.

90도 회전좌우·상하 반전미리보기
이미지를 선택하세요.
이미지 선택

사용방법

  1. 방향을 수정할 이미지를 선택합니다.
  2. 회전 또는 뒤집기 버튼을 사용합니다.
  3. 미리보기에서 방향을 확인합니다.
  4. 수정된 이미지를 저장합니다.

처리 기준과 주의사항

브라우저 캔버스 좌표계를 회전·반전한 뒤 이미지를 다시 그립니다. 회전 각도에 따라 출력 가로·세로가 서로 바뀔 수 있습니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

세로로 찍었지만 옆으로 누운 사진을 90도 회전해 정상 방향으로 저장할 수 있습니다.

자주 묻는 질문

여러 번 회전해도 되나요?

가능합니다. 90도 회전을 반복하면 180도·270도 방향도 만들 수 있습니다.

EXIF 방향정보도 수정되나요?

픽셀 자체를 다시 그리는 결과와 EXIF 메타데이터 처리는 별개일 수 있습니다.
