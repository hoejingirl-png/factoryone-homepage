현재 결제금액과 할인율, 정액쿠폰을 입력해 할인 전 가격과 실제 절약금액, 쿠폰까지 포함한 실질 할인율을 역산합니다.

사용방법

  1. 실제 결제금액을 입력합니다.
  2. 표시된 정률 할인율을 입력합니다.
  3. 추가 정액쿠폰이 있었다면 금액을 입력합니다.
  4. 할인 전 가격과 실제 할인액을 확인합니다.

계산 기준

정률할인 직후 가격 = 최종결제금액 + 정액쿠폰
할인 전 가격 = 정률할인 직후 가격 ÷ (1−할인율)

실제 사용 예시

20% 할인 상품을 68,000원에 샀다면 쿠폰이 없을 때 할인 전 가격은 85,000원으로 역산됩니다.

자주 묻는 질문

쿠폰이 먼저 적용된 경우도 같나요?

아니요. 할인 적용 순서가 다르면 결과가 달라집니다. 이 도구는 정률할인 후 정액쿠폰 차감으로 가정합니다.

포인트 사용도 할인으로 넣나요?

가격비교 목적에 따라 다릅니다. 실제 지출액 기준이면 포인트 사용을 별도 비용감소로 볼 수 있습니다.
