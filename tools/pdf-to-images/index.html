PDF 각 페이지를 이미지로 변환해 미리보고 저장합니다. 문서 일부를 이미지로 공유하거나 썸네일로 사용할 때 편리합니다.

사용방법

  1. PDF 파일을 선택합니다.
  2. 문서 페이지를 불러옵니다.
  3. 페이지별 이미지 변환 결과를 확인합니다.
  4. 필요한 이미지를 저장합니다.

처리 기준과 주의사항

PDF 페이지를 브라우저 캔버스에 렌더링한 뒤 이미지로 저장합니다. 출력 해상도는 렌더링 배율과 브라우저 성능의 영향을 받습니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

안내문 PDF 4페이지를 각각 PNG 또는 JPG 이미지로 만들어 메신저나 웹페이지에 사용할 수 있습니다.

자주 묻는 질문

벡터 PDF도 이미지가 되나요?

네. 화면에 렌더링한 결과를 이미지로 만드는 방식이므로 벡터 요소도 픽셀 이미지가 됩니다.

텍스트를 수정할 수 있나요?

이미지 변환 후에는 텍스트가 픽셀로 변환되므로 텍스트 편집 도구가 아닙니다.
