금융 계산은 가정값을 분명하게 보여주는 것이 중요합니다.

Factory One 금융 도구는 입력한 금리와 기간을 기준으로 수학적 결과를 계산합니다. 실제 금융상품의 우대금리, 일할계산, 중도상환, 세금, 수수료나 투자손실 가능성을 예측하지 않으며 각 페이지에 사용한 가정과 공식을 표시합니다.
