비율·비례식 계산기

A:B 비율을 가장 간단한 정수비로 줄이고, A:B=C:X 형태의 비례식에서 모르는 값을 계산합니다.

A:B 간소화비례식 X배수 비교

비율과 비례식 한 번에 계산

간단한 비율-
A:B 소수비-
A:B=C:X의 X-
A/B 배수-
B/A-

이 도구가 필요한 경우

이미지 비율, 혼합 비율, 도면 치수, 레시피 배수처럼 두 값의 관계를 줄여 보거나 같은 비율을 유지한 새 값을 구할 때 유용합니다.

핵심 포인트

  • 정수 입력은 최대공약수로 가장 간단한 비율을 찾습니다.
  • A:B=C:X 형태에서 X를 자동 계산합니다.
  • 몇 배 관계인지 소수 값도 함께 표시합니다.

사용 방법

1. A와 B 입력

원래 두 값을 입력합니다.

2. C 입력

같은 비율로 바꿀 새 기준값을 넣습니다.

3. 비율 확인

A:B를 간단한 정수비로 확인합니다.

4. X 확인

C에 대응하는 값을 자동으로 확인합니다.

계산·처리 기준

A:B=C:X에서 X=B×C÷A입니다. 정수비 간소화는 A와 B가 정수일 때 최대공약수로 나눕니다. 소수 입력은 소수비 자체를 우선 표시합니다.

실제 예시

1920:1080은 최대공약수 120으로 나누면 16:9입니다. 같은 비율에서 가로 C=1280이면 세로 X는 720이 됩니다.

자주 묻는 질문

소수 비율도 되나요?

계산은 가능합니다. 다만 가장 간단한 정수비 표시는 정수 입력일 때 가장 정확하고 직관적입니다.

16:9 화면의 세로를 구할 수 있나요?

A=16, B=9, C에 원하는 가로를 넣으면 X에 세로가 계산됩니다.

A가 0이면 어떻게 되나요?

0으로 나눌 수 없으므로 비례식 X는 계산할 수 없습니다.

퍼센트와 비율은 같은 건가요?

관련되지만 표현 방식이 다릅니다. 퍼센트는 100을 기준으로, 비율은 두 값의 상대 관계로 표현합니다.
