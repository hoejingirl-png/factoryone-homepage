PDF 페이지 번호 넣기

PDF 하단 또는 지정 위치에 페이지 번호를 추가합니다. 시작 번호를 조정해 보고서·제출문서의 페이지 체계를 정리할 수 있습니다.

페이지 번호 설정

PDF를 선택하세요.
번호는 각 페이지 하단 중앙에 추가됩니다.

페이지 번호

문서 제출용 PDF에 번호를 빠르게 추가할 때 유용합니다.

사용방법

  1. PDF를 선택합니다.
  2. 시작 번호와 번호 위치를 설정합니다.
  3. 전체 페이지에 적용할 결과를 확인합니다.
  4. 번호가 들어간 새 PDF를 저장합니다.

처리 기준과 주의사항

PDF 각 페이지에 페이지 번호 텍스트를 새로 추가합니다. 표지 제외 등 특수 번호 체계는 현재 옵션 범위를 확인하세요.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

표지를 포함한 12페이지 보고서에서 본문 첫 장을 1페이지로 보이게 시작 번호를 조절해 사용할 수 있습니다.

자주 묻는 질문

표지만 번호를 숨길 수 있나요?

현재 도구의 시작 페이지 또는 옵션 지원 범위를 확인해야 합니다.

기존 번호 위에 또 들어가나요?

기존 PDF에 이미 인쇄된 페이지 번호는 자동 인식해 제거하지 않습니다.
