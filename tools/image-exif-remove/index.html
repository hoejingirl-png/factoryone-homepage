사진 선택
Canvas 재인코딩 방식으로 메타데이터를 제거합니다.

사용방법

  1. EXIF를 제거할 사진을 선택합니다.
  2. 원본 이미지를 브라우저에서 불러옵니다.
  3. 메타데이터가 포함되지 않도록 새 이미지로 다시 생성합니다.
  4. 결과 파일을 저장해 사용합니다.

처리 기준과 주의사항

브라우저 캔버스에 픽셀을 다시 그려 새 파일을 생성하면 일반적인 EXIF 블록이 함께 복사되지 않는 특성을 이용합니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

스마트폰 사진을 공개 게시판에 올리기 전에 위치정보나 기기정보 노출이 걱정된다면 EXIF 제거 후 공유할 수 있습니다.

자주 묻는 질문

모든 메타데이터가 100% 없어지나요?

브라우저 재인코딩 방식은 일반 EXIF 제거에 효과적이지만 모든 특수 메타데이터 형식을 보장한다고 단정할 수는 없습니다.

화질이 변할 수 있나요?

출력 형식과 품질 설정에 따라 재인코딩으로 화질 또는 파일 크기가 달라질 수 있습니다.
