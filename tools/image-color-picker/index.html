이미지에서 원하는 지점을 선택해 색상값을 확인합니다. 디자인 참고색, 웹 컬러, 사진 속 색상 확인에 사용할 수 있습니다.

사용방법

  1. 색상을 확인할 이미지를 선택합니다.
  2. 미리보기에서 원하는 위치를 클릭합니다.
  3. 선택 지점의 색상값을 확인합니다.
  4. 필요한 HEX 또는 RGB 값을 복사해 사용합니다.

처리 기준과 주의사항

브라우저 캔버스에서 클릭한 좌표의 픽셀 RGBA 값을 읽어 색상코드로 표시합니다.

중요한 원본 파일은 별도로 보관하고, 결과 파일은 저장 후 한 번 열어 내용과 품질을 확인하는 것을 권장합니다.

실제 사용 예시

로고 이미지의 파란색과 비슷한 웹 버튼을 만들고 싶을 때 해당 지점을 클릭해 HEX 값을 확인할 수 있습니다.

자주 묻는 질문

화면에서 보이는 색과 실제 값이 다를 수 있나요?

색상 프로파일과 디스플레이 설정에 따라 체감색은 달라질 수 있지만 도구는 이미지 픽셀 값을 기준으로 읽습니다.

투명도도 확인되나요?

도구 구현에 따라 RGBA 알파값 확인 여부가 달라질 수 있습니다.
