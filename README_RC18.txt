Factory One RC18 - Local ROM Library

추가:
- 오락실 플레이어에서 사용자 ROM ZIP 직접 선택
- ROM 파일은 Factory One 서버로 업로드하지 않음
- IndexedDB 저장 옵션
- 다음 방문 때 '저장된 게임 실행'
- 저장된 ROM 삭제 버튼
- ROM NOT INSTALLED 개발문구 제거
- EmulatorJS 로컬 Blob 실행 방식 사용

실행:
START_FACTORYONE_RC18.bat
주소:
http://127.0.0.1:8028/
게임:
GAMES -> 오락실 게임 -> 내 게임 파일 실행
